# Public evidence redaction

This public copy replaces live AWS bucket/account/IAM identifiers and Rhombus workflow, job and source-version identifiers with example values or stable redaction labels. These are not usable cloud configuration values. Configure your own authorized assessment environment before running live tests.

Synthetic CSV bytes, validation outcomes and limitation disclosures are retained. Original infrastructure screenshots are omitted; the captioned walkthrough contains no cloud credentials or account identifiers. Unredacted evidence and its original history stay local and are not part of this repository. A redacted identifier is not independently verifiable run provenance.
